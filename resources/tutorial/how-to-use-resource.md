---
title: "Cara Mengunduh & Menggunakan File"
description: "Panduan dasar mendownload atau menyalin resource file."
category: "tutorial"
delivery_type: "text"
access_level: "free"
---

1. Klik tombol **Unduh File / Buka Tautan** di atas.
2. Jika berupa file (seperti PDF atau Excel), file akan tersimpan ke perangkat Anda. Jika berupa Notion Template atau Spreadsheet, Anda akan diarahkan ke halamannya.
3. Untuk template Notion/G-Docs, pastikan Anda menekan tombol **Duplicate** di pojok kanan atas layar agar tersalin ke akun Anda sendiri.
4. Setelah tersalin, Anda bebas mengedit dan menggunakannya.
